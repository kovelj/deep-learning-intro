## Introduction to Deep Learning with PyTorch

Welcome to this introduction to deep learning with PyTorch. This repository explores the explores the fundamental concepts behind deep learning, including neural network architectures, optimization, loss functions, and practical implementations using PyTorch, with all implementations written in Visual Studio Code, and Jupyter notebooks.

The notebooks are well-commented and mostly self-explanatory. Before running the notebooks, make sure that Python, Visual Studio Code, and the required extensions are installed. For setting up Python in VS Code, refer to the official documentation:

[VS Code Python setup guide](https://code.visualstudio.com/docs/python/python-tutorial)

The code in this repository has been tested on Linux. Other operating systems, such as Windows and macOS, have not been tested.

## Requirements

- Python 3.10+
- Visual Studio Code
- VS Code Python extension
- VS Code Jupyter extension

## Installation

Create a virtual environment:

```bash
python -m venv venv
source .venv/bin/activate
pip install -r requirements.txt
```
